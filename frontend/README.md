# Pinpoint frontend

Vite, React 19, TypeScript. See the root README for commands.

- `src/domain/` holds pure logic and types: the opening-hours rules, the timeline, trip edits. Tests sit next to each file.
- `src/features/` holds one folder per screen.
- `src/ui/` holds shared pieces: buttons, tags, fields, icons.
- `src/styles/tokens.css` holds every color, spacing value and font.
